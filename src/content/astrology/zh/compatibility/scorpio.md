## 天蝎座在寻找什么

天蝎座要么爱得深，要么不爱。它想要一个能完全信任的伴侣，这个人诚实、忠诚，不惧怕真实的感情。它给予强烈的投入，保护自己所爱的人。客套的闲聊、半真半假的话和耍心眼，会让它很快退缩。

占星师通常认为天蝎座与同样深沉的其他水象星座，以及它所尊重的稳重的土象星座很合得来。火象和风象星座带来活力和轻松，可能给天蝎座带来挑战，也可能让它焕然一新。这些描绘只看太阳星座，比较完整的星盘能看出更多。

## 天蝎座与火象星座

<a id="aries"></a>

### 天蝎座与白羊座

两个星座共享古典守护星火星，所以激情强烈。白羊座公开争斗，天蝎座讲究策略。权力之争可能爆发。当他们彼此信任时，就是大胆、忠诚、势不可挡的一对。

<a id="leo"></a>

### 天蝎座与狮子座

两个意志坚强的固定星座之间的四分相。狮子座开放而骄傲，天蝎座内敛而强烈。吸引力非常强。尊重、忠诚和避免嫉妒，能让这对戏剧性的组合走下去。

<a id="sagittarius"></a>

### 天蝎座与射手座

风格迥异的邻居。射手座开放、轻松、自由，天蝎座深沉、内敛。天蝎座想要的亲密，可能比射手座给的多。对重大问题、旅行或哲学的共同兴趣，能弥合差距。

## 天蝎座与土象星座

<a id="taurus"></a>

### 天蝎座与金牛座

有着磁石般吸引力的对宫星座。两人都忠诚、感性、固执。金牛座带来平静，天蝎座带来深度。嫉妒和固执己见可能发生冲突，但当信任牢固时，这份感情可以持续一生。

<a id="virgo"></a>

### 天蝎座与处女座

深思熟虑的六分相。两人都敏锐、注重隐私、忠诚。处女座带来清晰和关怀，天蝎座带来激情和深度。他们信任得慢，却很深，在严肃的目标上合作得很好。

<a id="capricorn"></a>

### 天蝎座与摩羯座

强大的六分相。两人都有抱负、意志坚定、忠诚。摩羯座带来结构，天蝎座带来情感深度。他们是一支令人敬畏的团队。两人都可能隐藏感情，所以坦诚的时刻很重要。

## 天蝎座与风象星座

<a id="gemini"></a>

### 天蝎座与双子座

耐人寻味的组合。双子座好奇而轻松，天蝎座强烈而内敛。天蝎座可能觉得双子座难以捉摸，双子座可能觉得天蝎座太沉重。对谜团和人的共同喜爱，能把他们拉到一起。

<a id="libra"></a>

### 天蝎座与天秤座

情绪不同的邻居。天秤座爱社交、迷人，天蝎座内敛、深沉。天秤座的优雅抚慰天蝎座，天蝎座的深沉吸引天秤座。坦诚和耐心能帮助信任成长。

<a id="aquarius"></a>

### 天蝎座与水瓶座

两个观点鲜明的固定星座之间的四分相。水瓶座看重自由和思想，天蝎座看重亲密和感受。他们可能发生冲突，但两人都忠诚而坚定。共同的事业或项目能帮他们找到共同点。

## 天蝎座与水象星座

<a id="cancer"></a>

### 天蝎座与巨蟹座

深沉的水象三分相。两人感受都很强烈，都看重忠诚。巨蟹座养育，天蝎座保护。他们一起创造一个安全而亲密的世界。情绪和嫉妒是仅有的阴云，信任能把它们驱散。

<a id="scorpio"></a>

### 天蝎座与天蝎座

两只蝎子无需言语就能理解彼此的深处。这段感情热烈、忠诚、强烈。风险在于权力之争或长久的沉默。坦诚和宽恕能让这对强大的组合共同成长。

<a id="pisces"></a>

### 天蝎座与双鱼座

温和的水象三分相。双鱼座带来温柔和想象，天蝎座带来力量和专一。在一起时，他们都感到被深深理解。天蝎座保护双鱼座，双鱼座让天蝎座变得柔软。
