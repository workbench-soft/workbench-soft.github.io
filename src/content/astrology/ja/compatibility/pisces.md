## 魚座が求めるもの

魚座は、魂の伴侶を夢見ます。やさしく、辛抱強く、気持ちを素直に分かち合える相手、自分の気分や夢を理解してくれる相手を求めます。やさしさ、想像力、深い思いやりを注ぎます。きつさ、冷たさ、冷笑は、魚座を深く傷つけます。

占星術師はふつう、魚座を感情の深さを共有するほかの水の星座や、安全な港を与える地の星座と組み合わせます。火と風の星座はエネルギーとアイデアをもたらし、魚にとっては刺激にも、圧倒される原因にもなります。以下のスケッチは太陽星座だけを見ています。ホロスコープ全体を比べれば、はるかに多くがわかります。

## 魚座と火の星座

<a id="aries"></a>

### 魚座と牡羊座

隣り合いながら、性質の違う二人です。牡羊座は大胆で率直、魚座は穏やかで夢見がちです。牡羊座は魚座を守り、魚座は牡羊座をやわらげます。牡羊座がペースを落とし、魚座が必要なことを口にすると、うまくいきます。

<a id="leo"></a>

### 魚座と獅子座

夢見るような組み合わせです。獅子座の温かさは魚座を引き寄せ、魚座のやさしさは獅子座の心にふれます。どちらも創造的でロマンチックです。獅子座は魚座の気持ちにやさしく接し、魚座は自分のために声を上げるとよいでしょう。

<a id="sagittarius"></a>

### 魚座と射手座

二つの柔軟宮のスクエアで、古い伝統ではどちらも木星に支配されています。どちらも理想主義的で気前がよい星座です。射手座は真理を、魚座はつながりを探します。精神的な夢や芸術的な夢を分かち合うことが、二人を結びつけます。

## 魚座と地の星座

<a id="taurus"></a>

### 魚座と牡牛座

穏やかなセクスタイルです。牡牛座は魚座に安らぎと安心を、魚座は牡牛座にロマンスと想像力を与えます。音楽と美しいものへの愛を共有しています。この組み合わせは、静かに幸せに感じられることが多いです。

<a id="virgo"></a>

### 魚座と乙女座

反対側の星座同士です。流れと秩序。乙女座は計画し、魚座は夢見ます。互いに相手が必要とするものを持っています。乙女座は魚座に枠組みを、魚座は乙女座に思いやりを与えます。やさしさが、このやさしい絆を健やかに保ちます。

<a id="capricorn"></a>

### 魚座と山羊座

支え合うセクスタイルです。山羊座は安定と守りを、魚座は温かさと想像力をもたらします。山羊座は魚座の足を地につけ、魚座は山羊座をやわらげます。この二人は、意外なほど献身的になれます。

## 魚座と風の星座

<a id="gemini"></a>

### 魚座と双子座

二つの柔軟宮のスクエアです。どちらも順応性と想像力に富みますが、双子座は考え、魚座は感じます。物語、音楽、芸術をいっしょに楽しめます。はっきりした計画とやさしい正直さがあれば、二人が流されずにすみます。

<a id="libra"></a>

### 魚座と天秤座

ロマンチックで芸術的な二人です。どちらも美しいものとやさしさを愛します。天秤座は優雅さを、魚座は夢をもたらします。穏やかで素敵な世界をつくります。どちらも争いを避けるので、問題を表に出すには、そっと背中を押すことが必要です。

<a id="aquarius"></a>

### 魚座と水瓶座

理想を持つ、隣り合う二人です。水瓶座はよりよい世界について考え、魚座はそこに生きる人々に心を寄せます。大義や創造的な仕事を分かち合えます。水瓶座は温かさを示し、魚座は自分の求めるものをはっきり伝えるとよいでしょう。

## 魚座と水の星座

<a id="cancer"></a>

### 魚座と蟹座

穏やかな水のトラインです。どちらもやさしく、直感的で、ロマンチックです。蟹座は世話を、魚座は夢をもたらします。二人でやわらかく安全な世界を築きます。支払いには、どちらかが目を配っておくとよいでしょう。

<a id="scorpio"></a>

### 魚座と蠍座

深い水のトラインです。蠍座は強さと献身を、魚座はやさしさと想像力をもたらします。いっしょにいると、深く理解されていると感じます。蠍座は魚座を守り、魚座は蠍座をやわらげます。

<a id="pisces"></a>

### 魚座と魚座

二匹の魚は、夢、芸術、感情に満ちた豊かな内面の世界を分かち合います。言葉なしで互いを理解します。危ないのは、実際の暮らしから離れて漂ってしまうことです。共通の日課と信頼できる友人が、二人が沈まずにいる助けになります。
