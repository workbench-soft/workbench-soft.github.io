## 獅子座が求めるもの

獅子座は、大きく気前のよい心で愛します。誇りに思える相手、自分を素直に称賛してくれて、ロマンス、楽しさ、少しの華やかさを楽しめる相手を求めます。一度心を決めると、誠実で、守ろうとします。冷たさ、人前での批判、無視されることは、獅子のプライドを傷つけます。

占星術師はふつう、獅子座をほかの火の星座や、その炎をあおる風の星座と相性がよいと見ます。地と水の星座は、ペースやスタイルは違っても、安定と深さをもたらします。以下は大まかなスケッチとしてお使いください。二人のホロスコープ全体を並べて比べれば、太陽星座よりはるかに多くがわかります。

## 獅子座と火の星座

<a id="aries"></a>

### 獅子座と牡羊座

明るい火のトラインです。牡羊座は勇気を、獅子座は温かさと華やかさをもたらします。冒険、お祝い、率直な会話を楽しみます。どちらもリードしたがるので、スポットライトを分け合うことが、この刺激的な二人を幸せにします。

<a id="leo"></a>

### 獅子座と獅子座

二頭の獅子は、華やかで、温かく、気前のよいカップルになります。パーティー、ロマンス、大きな見せ場が大好きです。どちらも称賛を必要とするので、もらいたい分だけ与えることを忘れないようにしましょう。そうすれば、二人いっしょに輝きます。

<a id="sagittarius"></a>

### 獅子座と射手座

喜びに満ちた火のトラインです。どちらも楽天的で、遊び心があり、気前がよい星座です。射手座は冒険とユーモアを、獅子座は誠実さと真心をもたらします。獅子座は、自由な射手座が向ける以上の注目を求めるかもしれませんが、たいていの溝は笑いが埋めてくれます。

## 獅子座と地の星座

<a id="taurus"></a>

### 獅子座と牡牛座

二つの不動宮のスクエアです。どちらもぜいたく、快適さ、誠実さを楽しみ、どちらも頑固になりえます。獅子座は拍手を、牡牛座は平穏を求めます。ときどき折れることを覚えれば、素敵な家を築けます。

<a id="virgo"></a>

### 獅子座と乙女座

隣り合いながら、スタイルの違う二人です。獅子座は輝き、乙女座は尽くします。乙女座は獅子座の計画を磨く手伝いができ、獅子座は乙女座が自分を信じる手助けができます。獅子は批判を深く受け止めるので、乙女座の指摘は温かく包む必要があります。

<a id="capricorn"></a>

### 獅子座と山羊座

やり方の違う、二つの野心的な星座です。獅子座はカリスマで、山羊座は戦略で導きます。二人で見事な暮らしを築けます。獅子座には山羊座が冷たく、山羊座には獅子座が派手に見えるかもしれません。共通の目標がその溝に橋をかけます。

## 獅子座と風の星座

<a id="gemini"></a>

### 獅子座と双子座

遊び心のあるセクスタイルです。双子座の機知は獅子座を楽しませ、獅子座の温かさは双子座を魅了します。ゲームと物語にあふれた、にぎやかな社交生活を楽しみます。獅子座は誠実さを必要とするので、双子座は心が家にあることを示すとよいでしょう。

<a id="libra"></a>

### 獅子座と天秤座

優雅なセクスタイルです。天秤座は獅子座のスタイルに感心し、獅子座は天秤座の魅力を愛します。美しいもの、芸術、ロマンスへの愛を共有しています。並ぶと絵になることが多く、よい暮らしを楽しみます。どちらもお世辞が好きなので、正直さには気配りが必要です。

<a id="aquarius"></a>

### 獅子座と水瓶座

反対側の星座同士です。心と集団。獅子座は個人的な献身を、水瓶座は自由と大義を求めます。互いの違いに惹かれ合います。獅子座が舞台を分け合い、水瓶座が温かさを分け合えば、創造的で誠実なチームになります。

## 獅子座と水の星座

隣り合う、どちらも愛する人を深く大切にする二人です。蟹座は育み、獅子座は守り、祝います。蟹座は獅子座の温かさを、獅子座は蟹座の献身を楽しみます。獅子座の社交生活と、蟹座の家を愛する気持ちのバランスをとる必要があります。

### 獅子座と蠍座

二つの力強い不動宮のスクエアです。惹かれ合う力は強く、双方の意志も同じくらい強いです。獅子座はオープンで、蠍座は秘密主義です。誠実さは深いですが、嫉妬も深くなりえます。尊重と信頼が、この激しい二人を結びつけます。

### 獅子座と魚座

夢見るような組み合わせです。魚座は獅子座の温かさに夢中になり、獅子座は魚座のやさしさを楽しみます。どちらも創造的でロマンチックです。獅子座は魚座の気持ちにやさしく接し、魚座ははっきり口にする必要があるかもしれません。芸術と共通の夢が二人を近づけます。
