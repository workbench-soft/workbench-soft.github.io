## 蠍座が求めるもの

蠍座は、深く愛するか、まったく愛さないかのどちらかです。完全に信頼でき、正直で、誠実で、本物の感情を恐れない相手を求めます。激しいほどの献身を注ぎ、愛する人を守ります。世間話、半分だけの真実、駆け引きには、すぐに身を引きます。

占星術師はふつう、蠍座を深さを共有するほかの水の星座や、その安定を蠍座が尊敬する地の星座と相性がよいと見ます。火と風の星座はエネルギーと軽やかさをもたらし、蠍にとっては試練にも、気分転換にもなります。以下のスケッチは太陽星座だけを見ています。ホロスコープ全体を比べれば、はるかに多くがわかります。

## 蠍座と火の星座

<a id="aries"></a>

### 蠍座と牡羊座

どちらも古くから火星を支配星とするため、情熱は強烈です。牡羊座は正面から、蠍座は戦略的に戦います。主導権争いが燃え上がることもあります。互いを信頼すれば、大胆で誠実な、止まることを知らない二人になります。

<a id="leo"></a>

### 蠍座と獅子座

意志の強い二つの不動宮のスクエアです。獅子座はオープンで誇り高く、蠍座は秘密主義で情熱的です。惹かれ合う力は強烈です。尊重、誠実さ、そして嫉妬を避けることが、このドラマチックな二人を結びつけます。

<a id="sagittarius"></a>

### 蠍座と射手座

隣り合いながら、スタイルのまったく違う二人です。射手座はオープンで軽やかで自由、蠍座は深く秘密主義です。蠍座は、射手座が与える以上の近さを求めるかもしれません。大きな問い、旅、哲学への共通の関心が、その溝に橋をかけます。

## 蠍座と地の星座

<a id="taurus"></a>

### 蠍座と牡牛座

磁石のように引き合う反対側の星座同士です。どちらも誠実で、五感を大切にし、頑固です。牡牛座は落ち着きを、蠍座は深さをもたらします。嫉妬と譲らない意見がぶつかることもありますが、信頼が強ければ、この絆は一生続くこともあります。

<a id="virgo"></a>

### 蠍座と乙女座

思慮深いセクスタイルです。どちらも洞察力があり、秘密主義で、誠実です。乙女座は明晰さと気配りを、蠍座は情熱と深さをもたらします。信頼するまでには時間がかかりますが、その信頼は深く、真剣な目標に向かっていっしょにうまく取り組めます。

<a id="capricorn"></a>

### 蠍座と山羊座

力強いセクスタイルです。どちらも野心的で、意志が固く、誠実です。山羊座は枠組みを、蠍座は感情の深さをもたらします。手ごわいチームになります。どちらも気持ちを隠しがちなので、正直になれる時間が大切です。

## 蠍座と風の星座

<a id="gemini"></a>

### 蠍座と双子座

興味をそそる組み合わせです。双子座は好奇心旺盛で軽やか、蠍座は情熱的で秘密主義です。蠍座には双子座がつかみどころなく、双子座には蠍座が重く感じられるかもしれません。謎や人間への共通の愛が、二人を近づけてくれます。

<a id="libra"></a>

### 蠍座と天秤座

隣り合いながら、雰囲気の違う二人です。天秤座は社交的で魅力的、蠍座は秘密主義で深い星座です。天秤座の優雅さは蠍座をなごませ、蠍座の深さは天秤座の興味をそそります。正直さと忍耐が、信頼を育てる助けになります。

<a id="aquarius"></a>

### 蠍座と水瓶座

強い意見を持つ二つの不動宮のスクエアです。水瓶座は自由とアイデアを、蠍座は近さと感情を大切にします。ぶつかることもありますが、どちらも誠実で意志が固い星座です。共通の大義や取り組みが、共通の基盤を見つける助けになります。

## 蠍座と水の星座

<a id="cancer"></a>

### 蠍座と蟹座

深い水のトラインです。どちらも強く感じ、誠実さを大切にします。蟹座は育み、蠍座は守ります。二人で安全で親密な世界をつくります。気分の波と嫉妬だけが雲で、信頼がそれを晴らします。

<a id="scorpio"></a>

### 蠍座と蠍座

二匹の蠍は、言葉なしで互いの深みを理解します。絆は情熱的で、誠実で、激しいものです。危ないのは、主導権争いや長い沈黙です。心を開くことと許すことで、この力強い二人はともに成長できます。

<a id="pisces"></a>

### 蠍座と魚座

穏やかな水のトラインです。魚座はやさしさと想像力を、蠍座は強さと献身をもたらします。いっしょにいると、深く理解されていると感じます。蠍座は魚座を守り、魚座は蠍座をやわらげます。
