## 射手座が求めるもの

射手座は、友人でもあり旅の仲間でもある相手を求めます。ユーモア、正直さ、好奇心、冒険への愛を求め、温かさ、気前のよさ、楽しさを注ぎます。嫉妬、厳しいルール、小さく閉じた世界は、射手座を地平線の彼方へ駆け出したくさせます。

占星術師によると、射手座はほかの火の星座や、アイデアへの愛を共有する風の星座と、すんなり流れ合います。地と水の星座は根と深さを与えてくれますが、射手はペースを合わせる必要があるかもしれません。以下は太陽星座だけを見たものです。ホロスコープ全体を比べれば、はるかに多くがわかります。

## 射手座と火の星座

<a id="aries"></a>

### 射手座と牡羊座

冒険好きな火のトラインです。どちらも自由、正直さ、行動を愛します。何年でもいっしょに旅し、スポーツをし、笑い合えます。実際的なことは誰かが把握しておく必要がありますが、この二人の中心にある友情は強いものです。

<a id="leo"></a>

### 射手座と獅子座

喜びに満ちた火のトラインです。獅子座は温かさと誠実さを、射手座はユーモアと冒険をもたらします。どちらも気前がよく楽天的です。獅子座は注目を求めるので、射手座はたびたび献身を示すとよいでしょう。

<a id="sagittarius"></a>

### 射手座と射手座

二人の射手は、のんびりした冒険好きのカップルになります。旅、アイデア、自由への愛を共有しています。危ないのは、どちらも計画を決めたがらないことです。大きな旅のような共通の夢が、二人に方向を与えます。

## 射手座と地の星座

<a id="taurus"></a>

### 射手座と牡牛座

不思議な組み合わせです。牡牛座は根と決まった習慣を、射手座は開けた道を求めます。牡牛座は射手に居心地のよい家を与え、射手は牡牛の世界を広げられます。お金と自由についてのはっきりした取り決めが助けになります。

<a id="virgo"></a>

### 射手座と乙女座

二つの柔軟宮のスクエアです。乙女座は細部を、射手座は全体像を見ます。どちらも学ぶことが大好きです。乙女座は射手座の大ざっぱさを心配し、射手座は乙女座を慎重すぎると感じるかもしれません。忍耐が本当の成長をもたらします。

<a id="capricorn"></a>

### 射手座と山羊座

隣り合いながら、スタイルの違う二人です。山羊座は計画し、射手座は夢見ます。山羊座は射手座が目標に届く手助けができ、射手座は山羊座がくつろいで笑う手助けができます。互いのペースを尊重することで、この二人はうまくいきます。

## 射手座と風の星座

<a id="gemini"></a>

### 射手座と双子座

反対側の星座同士で、好奇心の面では自然なパートナーです。双子座は事実を集め、射手座は意味を探します。いっしょに語り、旅し、学びます。どちらも自由を愛するので、深く結びつくには双方のはっきりした選択が必要です。

<a id="libra"></a>

### 射手座と天秤座

陽気なセクスタイルです。天秤座は優雅さと親しみを、射手座はユーモアと冒険をもたらします。文化、旅、人が大好きです。天秤座は率直な射手座に気配りを求めるかもしれませんが、どちらもすぐに許します。

<a id="aquarius"></a>

### 射手座と水瓶座

自由な心のセクスタイルです。どちらも自立、アイデア、友情を大切にします。大義、旅、未来についての長い語らいを分かち合えます。互いに余地を与え合うので、絆は新鮮なまま保たれます。

## 射手座と水の星座

二つの柔軟宮のスクエアで、古い伝統ではどちらも木星に支配されています。どちらも理想主義的でやさしい星座です。射手座は真理を、魚座は感情を通して意味を探します。精神的な夢や芸術的な夢を分かち合えます。はっきりした計画があれば、進む道からそれずにすみます。
