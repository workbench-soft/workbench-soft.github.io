## 双子座が求めるもの

双子座は、まず相手の頭の中に恋をします。夜遅くまで語り合え、同じ冗談で笑え、いつも驚かせてくれる相手を求めます。変化、友人、探検する余地が必要です。重苦しい決まりごとや束縛には落ち着かなくなり、好奇心と遊び心があればそばにいつづけます。

占星術師はよく、双子座のような風の星座は、アイデアへの愛を共有するほかの風の星座や、アイデアを行動に移す火の星座と最もうまくいく、といいます。地と水の星座は、ペースは違うかもしれませんが、双子座に根と深さを与えられます。以下のスケッチは太陽星座だけを使っています。ホロスコープ全体を比べれば、はるかに細かいことがわかります。

## 双子座と火の星座

<a id="aries"></a>

### 双子座と牡羊座

にぎやかなセクスタイルです。牡羊座は勇気とスピードを、双子座は機知とアイデアをもたらします。新しい場所や即興の計画を楽しみます。どちらもじっとしているのが苦手です。誰かが実際的な細かいことに目を配っていれば、二人は楽しくいられます。

<a id="leo"></a>

### 双子座と獅子座

これも明るいセクスタイルです。獅子座は観客が大好きで、双子座は楽しませたり褒めたりするのが大好きです。楽しむ心と忙しい社交生活を共有しています。獅子座は誠実さと注目を求めるので、あちこちへ向かう双子座の関心は、たびたび家に戻ってくる必要があります。

<a id="sagittarius"></a>

### 双子座と射手座

反対側の星座同士で、好奇心の面では自然なパートナーです。双子座は事実を集め、射手座は意味を探します。二人で旅し、学び、いつまでも語り合います。どちらも自由を愛するので、関係は軽やかに保たれます。深く結びつくには、両方が意識して選ぶことが必要かもしれません。

## 双子座と地の星座

<a id="taurus"></a>

### 双子座と牡牛座

双子座は何でも少しずつ試したく、牡牛座は一つのことをゆっくり味わいたいのです。牡牛には双子が散漫に、双子には牡牛が頑固に見えるかもしれません。ユーモアがあれば、双子座は落ち着いた家を、牡牛座は生き生きとした刺激を得られます。

<a id="virgo"></a>

### 双子座と乙女座

どちらも水星に支配されているので、考えることと話すことが大好きです。双子座は広く動き回り、乙女座は細かく見つめます。鋭く機知に富んだチームになれます。批判や神経質さが忍び込むことがあるので、ここでは言葉のやさしさがとても大切です。

<a id="capricorn"></a>

### 双子座と山羊座

慎重さが必要な組み合わせです。山羊座は長い目で計画し、双子座は今を生きます。山羊座は双子座の集中を助け、双子座は山羊座の肩の力を抜かせられます。鍵は、互いのまったく違うリズムを尊重することです。

## 双子座と風の星座

<a id="gemini"></a>

### 双子座と双子座

二人の双子座は、遊び心があっておしゃべりな、めったに退屈しないカップルになります。自由と変化を求める気持ちを互いに理解しています。危ないのは、つまらない用事がたまっていくことです。共有のカレンダーが、この楽しい組み合わせを救ってくれるでしょう。

<a id="libra"></a>

### 双子座と天秤座

気楽な風のトラインです。天秤座の魅力と双子座の機知はよく合います。芸術、人、よい会話を楽しみます。どちらも物事を心地よく保ちたいので、難しい話題は後回しになりがちです。正直に話すことで、絆は強く保たれます。

<a id="aquarius"></a>

### 双子座と水瓶座

アイデアにあふれた自然な風のトラインです。どちらも友情、自由、新しい考え方を大切にします。親友とパートナーを同時に兼ねられます。水瓶座はよそよそしく、双子座は落ち着きなく見えるかもしれませんが、互いにたっぷり余地を与え合います。

## 双子座と水の星座

<a id="cancer"></a>

### 双子座と蟹座

隣り合いながら、求めるものの違う二人です。双子座は感情について考え、蟹座は感情を感じます。蟹座は、最初のうち双子座が与えるよりも近い距離を求めるかもしれません。双子座が耳を傾け、蟹座が言葉で伝えれば、やさしく機知に富んだ家庭になります。

<a id="scorpio"></a>

### 双子座と蠍座

興味をそそる組み合わせです。蠍座は情熱的で秘密主義、双子座は軽やかでオープンです。蠍座には双子座が気軽すぎ、双子座には蠍座が重すぎるように感じられるかもしれません。謎や人間への共通の好奇心が、二人を近づけてくれます。

<a id="pisces"></a>

### 双子座と魚座

二つの柔軟宮のスクエアです。どちらも順応性と想像力に富みますが、双子座は考え、魚座は感じます。物語、音楽、芸術をいっしょに楽しめます。はっきりした計画とやさしい正直さがあれば、二人が流されずにすみます。
