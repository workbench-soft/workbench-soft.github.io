## 天秤座が求めるもの

天秤座はパートナーシップの星座で、愛をとても大切にします。やさしく、公平で、礼儀正しく、いっしょにいて楽しい相手、芸術、音楽、友人、長い会話を分かち合える相手を求めます。そのお返しに、魅力と思いやりを注ぎます。無礼、あからさまな争い、一方だけの努力は、天秤座を不幸にします。

占星術では、天秤座はほかの風の星座や、そのエネルギーを天秤座が釣り合わせる火の星座と、すんなり流れ合います。地と水の星座は深さと安定をもたらしますが、天秤座はそのリズムに合わせる必要があるかもしれません。以下は太陽星座による大まかなスケッチです。二人のホロスコープ全体を比べれば、もっと先まで見えてきます。

## 天秤座と火の星座

<a id="aries"></a>

### 天秤座と牡羊座

強く引き合う反対側の星座同士です。牡羊座は大胆で自分の意志で動き、天秤座は優雅でパートナーを大切にします。牡羊座は天秤座に行動することを教え、天秤座は牡羊座にほかの人を思いやることを教えます。惹かれ合う力は本物で、学びも本物です。

<a id="leo"></a>

### 天秤座と獅子座

華やかなセクスタイルです。獅子座は天秤座の魅力を愛し、天秤座は獅子座の温かさとスタイルに感心します。美しいもの、パーティー、ロマンスへの愛を共有しています。どちらも褒め言葉が好きなので、それが尽きることはめったにありません。

<a id="sagittarius"></a>

### 天秤座と射手座

陽気なセクスタイルです。射手座は冒険とユーモアを、天秤座は優雅さと親しみをもたらします。旅、文化、よい会話が大好きです。射手座のぶっきらぼうさは天秤座の気配りの感覚にさわるかもしれませんが、どちらもすぐに許します。

## 天秤座と地の星座

<a id="taurus"></a>

### 天秤座と牡牛座

美しいものと快適さへの愛を共有する、金星に支配された二つの星座です。牡牛座はプライベートを大切にして安定していて、天秤座は社交的で軽やかです。おいしい料理、芸術、素敵な家を楽しみます。どちらも急ぐのが苦手なので、決めごとには長い時間がかかるかもしれません。

<a id="virgo"></a>

### 天秤座と乙女座

洗練された好みを持つ、隣り合う二人です。乙女座は気配りと実際的な手助けを、天秤座は気楽さと魅力をもたらします。洗練された二人になります。乙女座の厳しい目はやさしさを保ち、天秤座は本当の意見を伝えるとよいでしょう。

<a id="capricorn"></a>

### 天秤座と山羊座

どちらもそれぞれのやり方でリードしたがる、二つの活動宮のスクエアです。山羊座は目標に、天秤座は人間関係に目を向けます。二人で、優雅で成功したチームになれます。ロマンスの時間をつくることで、山羊座の野心にすべてを奪われずにすみます。

## 天秤座と風の星座

<a id="gemini"></a>

### 天秤座と双子座

気楽な風のトラインです。双子座の機知と天秤座の魅力が、きらめく会話を生みます。友人、本、お出かけを分かち合います。どちらも難しい話題を避けがちなので、正直に話す少しの勇気が絆を深く保ちます。

<a id="libra"></a>

### 天秤座と天秤座

二人の天秤座は、品があり調和のとれたカップルになります。美しいもの、公平さ、平和への愛を共有しています。危ないのは、どちらも決めたがらず、問題を持ち出したがらないことです。選ぶ役を交代すれば、天秤がいつまでも揺れつづけることはありません。

<a id="aquarius"></a>

### 天秤座と水瓶座

自然な風のトラインです。どちらも人、アイデア、公平さを大切にします。水瓶座は独創性を、天秤座は優雅さをもたらします。よい友人にも、よいパートナーにもなれます。水瓶座は温かさを分け合い、天秤座は水瓶座に余地を与えるとよいでしょう。

## 天秤座と水の星座

<a id="cancer"></a>

### 天秤座と蟹座

どちらも人との関係を大切にする、二つの活動宮のスクエアです。蟹座は心の近さを、天秤座は調和と社交を求めます。どちらも思いやりがあります。ここでの主な課題は、相手の愛情の示し方を知ることです。

<a id="scorpio"></a>

### 天秤座と蠍座

隣り合いながら、雰囲気のまったく違う二人です。蠍座は情熱的で秘密主義、天秤座は軽やかで社交的です。蠍座の深さは天秤座を魅了し、天秤座の魅力は蠍座をなごませます。天秤座が心を開き、蠍座がやさしくあれば、信頼が育ちます。

<a id="pisces"></a>

### 天秤座と魚座

ロマンチックで芸術的な二人です。どちらも美しいもの、音楽、やさしさを愛します。魚座は夢を、天秤座は優雅さをもたらします。穏やかで素敵な暮らしをつくれます。どちらも争いを避けるので、問題を表に出すには、そっと背中を押すことが必要かもしれません。
